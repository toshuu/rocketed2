# Sri Ram eScooters — December 60% OFF Reel

A 20-second, 1080×1920 vertical HyperFrames promo reel. This version is intentionally **voiceover-free** and uses animated Hinglish/English on-screen copy.

## Render locally

Requirements: Node.js 22+ and FFmpeg.

```bash
npx --yes hyperframes doctor
npx --yes hyperframes lint
npx --yes hyperframes render --output sri-ram-escooters-december.mp4 --fps 30 --quality standard
```

## GitHub Actions

Pushes to `master` run the render workflow and upload `sri-ram-escooters-december-reel` as a downloadable Actions artifact. No TTS credentials are required.

## Ad-claim note

The 60% discount is presented exactly as supplied in the campaign brief. Before publishing, confirm eligible scooter models, the price basis, stock, offer dates, and applicable terms with Sri Ram eScooters. The reel avoids inventing range, battery, speed, warranty, or savings claims.
