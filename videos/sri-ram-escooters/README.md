# Sri Ram eScooters — December 60% OFF Reel

A 20-second, 1080×1920 vertical HyperFrames promo reel with an original Hinglish voiceover generated by Google Cloud Text-to-Speech.

## Render locally

Requirements: Node.js 22+, FFmpeg, and a Google Cloud API key with Cloud Text-to-Speech enabled.

```bash
export GOOGLE_TTS_API_KEY="your-key"
node generate-voice.mjs
npx --yes hyperframes doctor
npx --yes hyperframes lint
npx --yes hyperframes render --output sri-ram-escooters-december.mp4 --fps 30 --quality standard
```

## GitHub Actions

Add a repository Actions secret named `GOOGLE_TTS_API_KEY` with a restricted Google Cloud API key. The workflow generates `voice.mp3`, lints the composition, renders the MP4, and uploads it as the `sri-ram-escooters-december-reel` artifact.
