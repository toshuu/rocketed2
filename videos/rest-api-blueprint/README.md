# REST APIs — Blueprint Field Guide

A brand-new 60-second, 1080×1920, 30 fps REST API explainer, redrafted in the Blueprint style: white technical linework on Prussian blue, engineering-sheet framing, drafting annotations, and a single red approval stamp. The content remains a concise introduction to REST APIs, but the visual language is rebuilt from the whiteboard look into a blueprint sheet.

## Render
Requires Node.js 22+ and FFmpeg.

```bash
npx hyperframes doctor
npx hyperframes lint
npx hyperframes render --output rest-api-blueprint.mp4 --fps 30 --quality standard
```

The GitHub Actions workflow validates and renders the MP4, uploads it as a workflow artifact, and publishes a direct-download release asset.

## Specs
- 60 seconds
- 1080×1920 portrait
- 30 fps
- Caption-led, no voiceover
- Blueprint visual language: cyanotype blue sheet, pale technical linework, dimensions/grid treatment, and one red stamp
